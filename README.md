# CineVerse — Movie Information Website

A responsive movie information webpage built with pure HTML, CSS, and JavaScript.

## Features
- **Movie Poster & Hero Banner**: Displays high-contrast SVG posters (works offline), certification badge, release year, duration, language, and genre tags.
- **Story Information & Key Details**: Full storyline, highlights, director, writers, music composer, and production details.
- **Cast Section**: Styled cast cards showing actor names and character roles.
- **Ratings & Reviews**: IMDb rating, Critics score, interactive 5-star user rating, and audience review submission (saved in `localStorage`).
- **Trailer Section**: Embedded YouTube trailer player with a direct fallback link.
- **Related Movies & Live Search**: Click any related movie or use the search bar to dynamically switch movies.
- **Watchlist**: Save and manage favourite movies in a modal drawer.

## How to Run
1. Extract `movie-information-website.zip`.
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
